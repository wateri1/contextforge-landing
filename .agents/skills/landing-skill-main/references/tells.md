# Признаки шаблонного лендинга

Этот список я собрал из двух чужих чеклистов "почему ваш сайт выглядит как вайб-код" и из собственных прогонов, где смотрел, что модель делает по умолчанию. Часть пунктов из тех чеклистов я выкинул как вкусовщину, часть дописал сам.

Это симптомы для проверки готовой страницы, а не правила для сборки. Почти ни один пункт не запрещён сам по себе: если решение осознанно выведено из предмета страницы, оно остаётся. Плохо, когда признаков несколько и ни один никто не выбирал. Исключений два: группа "Неправда" и звёздочка-"искра", их я убираю всегда.

Замена признака на его ближайшего соседа ничего не исправляет. Я это видел сам: стоило запретить один шаблон, как на его месте появлялся следующий. Сине-фиолетовый градиент, заменённый на бежевый фон с терракотовым акцентом, и Inter, заменённый на Space Grotesk, дают такой же узнаваемый шаблон следующего поколения.

## Неправда

Самая тяжёлая группа, исправляется всегда.

| Признак | Что делать |
|---|---|
| Выдуманные отзывы, имена, должности, фото клиентов | Убрать секцию или взять отзывы из ТЗ |
| Счётчики и метрики без источника ("10 000+ клиентов", "99,9%") | Убрать или заменить цифрой из ТЗ |
| Логотипы "нам доверяют" без подтверждения | Убрать |
| Сгенерированные или стоковые фото "команды" и "офиса" | Убрать, показать продукт или обойтись без фото |
| Форма, которая показывает успех, ничего не отправляя | Подключить отправку или явно пометить место подключения |

## Текст

| Признак | Что делать |
|---|---|
| Размытый заголовок первого экрана ("Раскройте потенциал вашего бизнеса") | Сказать, что это и для кого |
| Набор модных слов: инновационный, бесшовный, под ключ, экосистема, нового поколения | Заменить фактом: числом, сроком, названием, примером |
| Тройки прилагательных и одинаковый ритм у всех абзацев | Переписать так, как сказал бы владелец бизнеса вслух |
| Кнопки "Начать", "Узнать больше", "Попробовать" | Назвать то, что произойдёт после нажатия |
| Эмодзи в заголовках и вместо иконок | Убрать или заменить иконками в одном стиле |
| В английском тексте длинное тире в каждом втором предложении | Перестроить фразы. В русском тексте тире нормально, его не трогать |
| Плашка "сделано с помощью ИИ" или подпись конструктора | Убрать |

## Структура

| Признак | Что делать |
|---|---|
| Порядок "первый экран, три преимущества, отзывы, тарифы, призыв" независимо от продукта | Пересобрать от вопросов посетителя |
| Три карточки с иконкой, заголовком и двумя строками текста в ряд | Подобрать форму под содержимое: шаги, таблица, список, схема |
| Плашка-бейдж над главным заголовком | Убрать, если она не сообщает ничего важного |
| Все секции одной высоты и одной композиции, текст везде по центру | Задать ритм: плотные и просторные секции, смена выравнивания |
| Секции, которые есть "потому что так принято" (FAQ из очевидных вопросов, "наши ценности") | Убрать |

## Визуальный стиль

| Признак | Что делать |
|---|---|
| Дизайн без признаков отрасли: если заменить название, страница подошла бы кофейне, клинике или сервису доставки | Добавить изображение предмета услуги на первый экран и мотив бренда, повторяющийся по странице |
| Логотип-галочка, буква в квадрате или абстрактная фигура, не связанная с услугой | Знак из мира услуги, тот же мотив в иконках и деталях |
| Четырёхконечная звёздочка-"искра" (✦, sparkle) где угодно: в кнопках, маркерах списков, логотипе, иллюстрации. Это общепринятый значок ИИ-функций, и он выдаёт страницу сильнее любого градиента | Убрать везде. Чистоту, блеск, новизну и "магию" показывать иначе: бликом-полосой на поверхности, каплей, пузырём, конкретным предметом |
| Декоративный значок внутри кнопки (звёздочка, стрелка, ракета, молния) без смысла | Кнопка из одного текста. Значок только если он сообщает действие: телефон у звонка, скачивание у файла |
| Сине-фиолетовый градиент на фоне или кнопках | Вывести палитру из предмета |
| Градиентная заливка текста заголовка | Сплошной цвет, акцент размером и начертанием |
| Карточки с эффектом матового стекла | Плоские поверхности с ясной иерархией |
| Карточки с цветной полоской-границей сбоку или сверху | Различать содержимым, а не рамкой |
| Зернистая текстура поверх градиента | Убрать, если фактура не связана с предметом |
| Тёмная тема с серым текстом на тёмно-сером | Поднять контраст до 4,5:1 |
| Inter или другой шрифт по умолчанию для всего | Выбрать гарнитуру под характер продукта, проверить кириллицу |
| Пара "гротеск плюс курсивная засечка для одного слова в заголовке" | Тот же шаблон, только новее. Выбрать осознанно или убрать |
| Компоненты shadcn/ui без единой правки | Перенастроить под свои переменные: радиусы, цвета, отступы, шрифт |
| Иконки Lucide в каждой карточке | Оставить там, где иконка помогает понять, остальные убрать |
| Кнопки-пилюли везде | Форма кнопки из общего решения по радиусам |
| Отступы, которые не складываются в шкалу | Привести к одной шкале |
| Одинаковая тень и одинаковое скругление на всём | Различать уровни: что лежит на странице, что над ней |

## Движение

| Признак | Что делать |
|---|---|
| Каждая секция проявляется при прокрутке | Оставить один-два осмысленных момента или убрать |
| Свечение или пятно, следующее за курсором | Убрать |
| Изменённый курсор | Убрать |
| Кнопки, у которых при наведении только меняется прозрачность | Ясное состояние наведения плюс видимый фокус с клавиатуры |
| Анимация без учёта `prefers-reduced-motion` | Добавить отключение |

## Незаконченность

| Признак | Что делать |
|---|---|
| Нет favicon или стоит значок фреймворка | Сделать свой, SVG достаточно |
| Заголовок вкладки "Vite App", "Document", пустое описание | Написать `title` и `meta description` |
| Нет политики конфиденциальности и условий использования | Сделать страницы и ссылки на них |
| Нет Open Graph картинки, ссылка в мессенджере без превью | Добавить |
| Ссылки `href="#"`, соцсети в никуда | Убрать или подключить |
| Нет страницы 404 | Сделать |
| Сайт на техническом поддомене хостинга | Вне вёрстки. Напомнить владельцу про свой домен в отчёте |
| На мобильной ширине горизонтальная прокрутка, обрезанные заголовки | Исправить и проверить на 360 px |
