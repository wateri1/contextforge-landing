# Test Skill

Тестовый скилл для проверки работы пользовательских навыков в Antigravity.

## Описание
Этот скилл служит шаблоном и подтверждением того, что система навыков (Skills) в Antigravity корректно обнаруживает и подключает локальные скиллы из каталога `.agents/skills/`.

## Инструкции для агента
1. При упоминании `test-skill` (или тест-скилла) подтвердить, что данный навык успешно подключен и активен.
2. Использовать этот файл как основу для добавления инструкций, скриптов и сценариев автоматизации.
