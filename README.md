# ContextForge — AI-Native Engineering Course Landing Page

> **Terminal-native landing page for an advanced AI software engineering course.**  
> Built with pure HTML5, Modern CSS, and Vanilla JavaScript. Zero external frameworks, zero dependencies, instant load time.

---

## 🖥 Overview & Concept

**ContextForge** is a high-converting, developer-focused portfolio landing page designed with an authentic **CLI / TUI (Terminal User Interface)** aesthetic:
- **Typography:** 100% `JetBrains Mono` monospace typography across all headings, body text, buttons, and telemetry.
- **Palette:** Deep matte CRT substrate (`#090b0e`), ANSI Terminal Green (`#33ff33`), ANSI Red (`#f85149`), and muted telemetry borders.
- **No AI-Slop:** Zero blurry neon glows, zero fuzzy gradients, zero fake social counters. Pure engineering precision.

---

## ⚡ Key Interactive Features

1. **Interactive Hero IDE Terminal Player**
   - 5-step interactive workflow:
     1. `01 PRD` — Spec-Driven prompt definition.
     2. `02 Guardrails` — Strict `.cursorrules` system configuration.
     3. `03 Supabase` — Safe SQL migration with mandatory Row-Level Security (RLS).
     4. `04 Next.js` — Type-safe Server Action with Zod validation.
     5. `05 E2E Tests` — Autonomous agent test pass output.
   - Autoplay loop with progress indicator, manual step tabs, and play/pause controls.

2. **CLI Anti-Hype Comparison Matrix**
   - Side-by-side terminal diff comparing chaotic web-chat prompting (`[-] ERR_CHAT_PROMPT`) against structured context engineering (`[+] OK_CONTEXT_ENGINE`).

3. **Live Starter Kit Inspector**
   - In-browser viewer for a production-grade `.cursorrules` configuration file.
   - 1-click clipboard copy with terminal toast notifications.

4. **Telemetry Bento Grid Curriculum**
   - 4 modular courses presented in a gapless CSS Grid:
     - Module 01: Context Architecture & Spec-Driven Development
     - Module 02: Hard Guardrails: `.cursorrules`
     - Module 03: Supabase, Auth & Database Integrity
     - Module 04: Terminal Agents & Autonomous Debugging

5. **Terminal Contract Pricing & Risk Reversal**
   - Clear tier comparison (`Инженер` & `Архитектор`) with installment options and a 7-day unconditional refund policy.

6. **Accessible Modals & Responsive Layout**
   - 40-minute workshop registration modal with focus trapping and demo mode notification.
   - Tested responsive layout from 360px mobile viewport up to 4K displays.

## 🛠 Tech Stack

- **HTML5:** Semantic, accessible markup (ARIA attributes, WCAG AA compliance).
- **CSS3:** Custom Properties, CSS Grid (`grid-auto-flow: dense`), Flexbox, responsive clamping.
- **JavaScript (ES6+):** Vanilla DOM controllers, requestAnimationFrame animations, clipboard API.
- **Fonts:** JetBrains Mono via Google Fonts.

## 🚀 Quick Start

Simply open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/wateri1/contextforge-landing.git

# Open directly in browser
open index.html # On macOS
start index.html # On Windows
```

Or run a local server:

```bash
python -m http.server 3000
```
